# 色

| トークン | 値 | 用途 |
| --- | --- | --- |
| canvas / surface | `#FFFFFF` | キャンバス・必要な製品枠の内部 |
| region | `#F5F6F7` | 基盤や横断機能の背景 |
| region-accent | `#EDF3F8` | 説明の中心になる領域1か所の補助背景 |
| text | `#202124` | 製品名、本文 |
| text-secondary | `#5F6368` | 役割、注記 |
| border | `#AEB8C4` | 外側の領域枠 |
| inner-border | `#D0D6DD` | 製品内・論理層の内枠 |
| heading | `#EEF1F4` | 枠と一体の見出し帯 |
| connector | `#5F6368` | データ線、制御線 |
| accent | `#3569A8` | 説明対象の経路・見出しの限定的な強調 |
| attention | `#9A6700` | 必要な要確認注記 |

公式アイコンは配布された色と形を保つ。この表の色数制限は、公式アイコン自体の色には適用しない。独自の色分けはアクセント1色を基本とし、別の意味を持つ経路を強調するときだけ2色目を使う。その場合も線種・ラベルで意味を示す。

共有SVG部品の値は[design-tokens.json](../../assets/design-tokens.json)を使用する。工程枠、所属の薄い背景、製品の白い内部を階層として使い、色だけで別の意味を増やさない。破線の領域は責任・契約等の意味をラベルで明示する。
