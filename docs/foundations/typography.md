# 文字

日本語はNoto Sans JP、ヒラギノ角ゴ、游ゴシック等のサンセリフ書体。共通SVG部品では領域見出し24px、所属・製品領域名22px、製品・処理名24px、役割22pxを初期値とする。掲載寸法と情報量に合わせて調整する。太字はタイトルと主要見出しに絞る。

製品名と用途の書き方は[ラベルと注記](../components/annotation.md)に従う。

## 掲載寸法での判断

元データのpx値だけで読みやすさを判断しない。表示時の文字サイズは「元の文字サイズ × 掲載幅 ÷ キャンバス幅」で確認する。ブログは幅960px、スライドは幅1280pxを確認用の初期値とし、実際の掲載寸法が分かる場合はそちらを使う。

ブログ幅960pxでは製品名12px以上、補足11px以上を最低の目安とし、可能なら14px以上にする。小さくなる場合は文字を大きくし、改行・ラベル短縮・工程間隔の見直しを行う。縮小した図の全体表示で読めない場合は概要と詳細を分ける。2倍解像度のPNG出力だけでは表示上の文字サイズは改善しない。

例えば幅1920pxの図を幅960pxで掲載する場合、製品名24px・補足22pxは表示時12px・11pxになる。投影するスライドは会場・画面の条件もあるため、最終スライドの全体表示で主経路と製品名を確認する。
