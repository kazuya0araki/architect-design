# 部品の仕様と見本

部品は掲載幅で選ぶ。以下の寸法は初期値であり、名前を小さくして固定枠へ押し込む制約ではない。標準文字は名前24px・役割22px、公式アイコンは56px、外周48px、ノード内余白16pxを基本とする。共有実装のlogical/dataは文字領域8pxを下限として折り返すため、配置時にはさらに余白を確保する。

| 部品 | 適用条件・初期寸法 | 可変部分 | 禁止例 |
| --- | --- | --- | --- |
| `icon` | 製品が確定。アイコンと下の名称・役割を収める高さ | ノード幅・高さ、明示改行 | 未確認製品へのロゴ割当、ロゴ変形 |
| `horizontal` | 横断機能や利用先。アイコン右側に文字 | 幅、役割の行数 | 狭い幅で名前を極小化 |
| `logical` | 製品未定の処理・内製機能。192×96を初期値 | 内容に応じた幅・高さ | 全ノードを同じ寸法に固定 |
| `data` | 製品内の論理データ。224×112を初期値 | 層名・役割 | RawとMartに同じ製品アイコンを重複 |
| 製品領域 | 製品名、内部データ、接続通路。見出し48px | 子要素と通路による寸法 | 製品とクラウド所属の混同 |
| 接続 | 片方向、線幅1〜1.5px。実線はデータ、破線は制御 | 方式・データ名等の既知のラベル | 方式ごとに既存の線種の意味を変更 |

[部品の組み合わせ見本](../../examples/component-catalog/README.md)と[ノードの状態別見本](../../examples/node-specimens/README.md)を参照する。後者は標準、長文、アイコンなし、横並び、製品内の入れ子を並べた作図用資料であり、接続のない見本間に連携が存在することを意味しない。

公式アイコンの見本は[Google Cloud例](../../examples/google-cloud-analytics/README.md)を参照する。新しいブランド素材は追加せず、確認済みのassetsを使う。
