# 横断機能

オーケストレーション、データ品質、カタログ、監視、アクセス管理、CI/CD、IaC等を、対象の主経路とは分けて示す。必要なものだけを配置し、図を埋めるために製品や管理機能を追加しない。

オーケストレーションは対象の下部の横長領域に置く。品質・カタログ・認証・開発運用は、意味が異なる場合は別の小区画または横帯とする。すべてを同じ「データ処理」の矢印で連結しない。

- 実行管理: 対象の処理または所属領域へ破線の制御線を引く。
- 品質検証: 検査対象と、実装がある場合だけ通知先を示す。
- カタログ・メタデータ: データの保存・移動ではなく、管理対象との関係を示す。
- IAM・認証: 確認できた対象・権限の関係を説明する。枠だけでアクセス制御の保証を示さない。
- CI/CD・IaC: 作成・配備・管理する対象を示す。運用上の所属とデータフローを分ける。

広く対象に効く機能は領域に接続してよい。個々のノードへ破線を大量に引かず、対象範囲を名前と所属から読めるようにする。線のない並びは機能の一覧であり、制御や連携が存在するという主張にはしない。
