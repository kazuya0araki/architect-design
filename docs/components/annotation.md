# ラベル・凡例・注記

製品名は正式表記で1〜2行、役割はその下に小さく配置する。例: `BigQuery`の下に`分析用データセット`。製品名と用途を毎回スラッシュで連結しない。見出し・ラベルの言語は日本語を基本に揃え、製品名やRaw、Mart等は元の表記を使う。

同じデータが続く線ではラベルを繰り返さない。処理方式やデータが変わる場所に絞って記載する。確認できない更新頻度や製品は補完しない。

凡例は使った線種だけを説明する。破線の境界枠と破線の制御線は形と見出しで区別する。番号付き経路は手順を追う図に限り、対応する説明を添える。強調色や番号だけで意味を伝えない。

タイトル、目的説明、凡例、前提、出典、未確認事項は付随Markdownへ置く。画像内への追加は明示の指定がある場合に限る。ノードや領域の名前、役割、接続ラベルは図の構成要素として表示する。
