# 論理層

Raw、Staging、Warehouse、Mart等は、同一製品内の論理層として内側の小区画で示す。製品と同じ大きさのアイコンを層ごとに繰り返さない。層名・層数は案件の定義に合わせ、空の層やサービスを追加しない。

[段階的な変換](../patterns/layered-pipeline.md)と[公式アイコン付きの例](../../examples/google-cloud-analytics/README.md)を参照する。

共有SVG部品では`product`領域の中へ`data`または`logical`ノードを置き、製品名と公式アイコンは領域ヘッダーに一度表示する。層の順序を左から右に置き、層間の変換と変換を実行するツールを区別する。同じ製品でもプロジェクト・責任境界が異なる場合は別領域を保持する。
