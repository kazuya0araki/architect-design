# コピーを伴わない外部照会

外部データを基盤へコピーする転送と、外部システムへクエリを実行する照会を区別する。照会だけを根拠に基盤内へRawや保存先を追加しない。永続化・キャッシュ・一時領域は実装上確認できた場合だけ描く。

| interaction | 意味 | kind |
| --- | --- | --- |
| `transfer` | 複製・ロード等のデータ移動 | `data` |
| `query` | クエリ実行の要求 | `control` |
| `result` | 照会・参照結果 | `data` |
| `metadata` | スキーマ・カタログ等のメタデータ移動 | `data` |

これは関係の補助分類であり、`purpose`の業務上の目的と別項目である。メタデータの移動と権限付与・管理指示も混同しない。

外部システムを左、クエリエンジンを中央、利用者を右に置く。要求は右から左への破線、結果は左から右への実線として別経路にする。この逆向きの要求は処理工程の折り返しではない。右から左へ実データを返す配置では`return_path: true`と目的も必要になる。

[外部照会の例](../../examples/federated-query/README.md)を参照する。データ共有も「転送」「照会」「カタログ参照」の実際の方式を確認し、共有という名前だけで全てを同じ線にしない。
