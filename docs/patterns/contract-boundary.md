# 契約による境界

## 適用条件

スキーマ変更の影響や所有権を説明する場合に選ぶ。

## 表現規則

契約による境界では、提供インターフェースを論理要素として示し、その管理主体を添える。製品やDBの枠だけで契約の存在を表さない。

必要な情報が未確認なら提案または未確認事項として明記する。特定の製品を必須にしない。

[構成パターンの選択](README.md)に戻る。

## 配置と部品

提供側チームと分析側チームの間へ名前付きの公開インターフェースを置く。データ契約と製品・保存先を別要素にし、確認できた品質検査や通知だけを下部へ示す。図の枠が実行時の検証・遮断を実装するものではない。

[契約と責任境界の例](../../examples/contract-boundary/README.md)を参照する。
