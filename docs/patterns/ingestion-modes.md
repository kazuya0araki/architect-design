# バッチ・ストリーミング・CDC

取り込み方式が説明に必要な場合、接続に`interaction: transfer`と`transfer_mode`を記録する。値は`batch`、`streaming`、`cdc`。方式は図の線種を増やすために使わず、必要なラベルと並行レーンで説明する。

- バッチ：ファイルやレコードをまとめて取り込む。日次等の頻度は確認できた場合のみ`frequency`へ記録する。
- ストリーミング：イベントを継続的に処理する。リアルタイム・遅延保証を方式名だけから補わない。
- CDC：DB等の変更を取得する。CDC自体は実行頻度ではなく、バッチでも継続処理でも実装される。頻度は別項目で記録する。

実線はデータ、破線は制御という既存の意味を維持する。矢印は左から右へ配置し、ラベルは「変更を転送」「まとめて取得」等、確認済みの役割を簡潔に示す。`transfer_mode`は内部メタデータであり自動的にラベルへ追加しない。

[方式別の見本](../../examples/ingestion-modes/README.md)は3方式を比較する架空の提案。実案件で3方式を全て追加するテンプレートではない。
