# 段階的な変換

## 適用条件

処理責務や変換段階を説明する場合に選ぶ。

## 表現規則

段階的な変換では、取り込み・加工・提供を区別する。同一製品内のRaw・Staging・Warehouse・Mart等は論理層としてまとめ、実際の定義に合わせて必要な層だけを表示する。

必要な情報が未確認なら提案または未確認事項として明記する。特定の製品を必須にしない。

[構成パターンの選択](README.md)に戻る。

## 配置と部品

接続元・取り込み・保存／加工・活用を機能のまとまりとして囲い、その内側へ所属と製品領域を置く。製品の内部にRaw・Mart等を配置し、実行管理は下部へ分離する。[論理例](../../examples/analytics-platform/README.md)と[公式アイコン例](../../examples/google-cloud-analytics/README.md)は同じ接続構造を使う。
