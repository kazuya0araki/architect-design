# データ・AI基盤

## 適用条件

分析以外の活用やReverse ETLを対象にする場合に選ぶ。

## 表現規則

データ・AI基盤では、共通の保存・加工からBI、AI、業務システム等へ分岐する。業務システムへ戻す経路はReverse ETL等の目的を記し、入力経路と分ける。

必要な情報が未確認なら提案または未確認事項として明記する。特定の製品を必須にしない。

[構成パターンの選択](README.md)に戻る。

## 配置と部品

利用先はBI、AI・分析、業務プロダクト等の目的でまとめる。モデル学習、推論、検索、配信は案件の対象範囲に応じて別経路として示す。複数製品の併用は製品領域で分け、データ共有・外部参照・複製を同じものとして描かない。主経路は左から右、実際の書き戻しは目的を明記する。

[BI・AI・業務への分岐例](../../examples/data-ai-platform/README.md)を参照する。
