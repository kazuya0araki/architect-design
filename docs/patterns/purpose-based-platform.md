# 用途別の基盤

## 適用条件

利用目的、利用者、責務が異なる場合に選ぶ。

## 表現規則

用途別の基盤では、処理ステージを横方向、用途別レーンを縦方向に揃える。担当が異なる場合は所有チームと責任境界を明記する。

必要な情報が未確認なら提案または未確認事項として明記する。特定の製品を必須にしない。

[構成パターンの選択](README.md)に戻る。

## 配置と部品

用途別のレーンには、何が異なるか（利用目的・所有チーム・対象サービス）を明記する。工程の並びは揃え、各レーンのノードや空の層を無理に同数へ揃えない。クラウドやプロジェクトは各レーン内の所属として別に表す。共有する機能は下部にまとめ、共有していない実装を一つに見せない。

[用途別の例](../../examples/purpose-based-platform/README.md)を参照する。
