# デザインシステムの概要

本システムは、データの流れ、各処理の責務、運用上の境界をAI Agentが一貫した図と説明に変換するための規則である。対象は構成図と付随する説明であり、製品選定の正解や実装構成を一律に規定するものではない。

読み手はデータエンジニア、プロダクト開発者、基盤の利用者。最初に「どこから来て、どう処理され、誰に届くか」が読み取れ、必要に応じて運用責務を追えることを目指す。

編集可能な構成図と説明を成果物とする。構成検討はMermaid、公開用の完成図はSVGまたはdraw.ioを使う。

[最初の1枚を作る](quick-start.md)から始め、[ドキュメント一覧](../README.md)で必要な規則を選ぶ。
